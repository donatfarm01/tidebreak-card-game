Tidebreak is an original two-player duel card game: two lighthouse keepers battle over a stormy strait. Each round you play one card against the Stormkeeper AI; a card matching the rotating tide counts double, Storm Surge adds +3, and Anchor blocks all damage that round. Higher total wins the trick and deals the difference as damage — first to reduce the rival to 0 life wins.

## Run it

```sh
node serve.mjs
```

Then open http://localhost:8080 in a desktop browser. No network requests: the game is plain static files under `game/`, played with mouse or keys 1–5.
